## Enterprise Standards

### Communication Style

- Use clear, professional language
- Follow enterprise documentation standards
- Reference internal wikis and guidelines where appropriate

### Code Quality Priorities

When reviewing or generating code, prioritize:

1. **Security** - Follow enterprise security policies
2. **Compliance** - Adhere to regulatory requirements
3. **Maintainability** - Follow team coding standards
4. **Performance** - Meet SLA requirements

### Feedback Categories

| Level | Description |
|-------|-------------|
| 🔴 Critical | Security issues, compliance violations |
| 🟠 Major | Significant quality issues |
| 🟡 Minor | Style issues, small improvements |
| 🔵 Suggestion | Optional enhancements |
